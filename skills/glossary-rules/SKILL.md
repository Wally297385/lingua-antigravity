# 术语领域判据 (@skill(glossary-rules))

glossary 承载普通翻译无法稳定推出的专有译法、身份、消歧和世界观事实。运行时按 `src` 连续字面命中激活条目，把 `src -> dst #info` 注入模型。

---

## 1. 收录资格与边界判定

先独立判断对象是否需要 glossary，再判断怎样表达：

- **应收录**：专有实体、人名、别名、地名、组织、特定物品、技能、世界观专有概念；缺少 glossary 会导致破坏一致性的语义漂移或分歧。
- **不应收录（硬红线，严禁入表）**：
  1. **常规人名敬称称谓**：`人名 + (君|先生|先輩|さん|ちゃん|様|さま|殿等)` 严禁作为独立条目录入（如 `日向君`、`金森先生`、`木枯先輩`）。人名由核心名统领，常规后缀属于日汉翻译通用语法，下游 LLM 会根据人际语境动态自然处理。强行入表会导致词库膨胀与匹配竞争。*仅当该称呼带有特殊反差代号、黑话或双关文学设定时方可收录*。
  2. **修饰扩展与嵌套长词**：当核心专名实体（如 `大園高校`、`濃硫酸女`）已被收录时，带有通用限定/从属前缀（如 `私立`、`理科室の`、`市立`、`旧`）的长词（如 `私立大園高校`、`理科室の濃硫酸女`）严禁重复收录，保持单一核心实体；
  3. **大模型已知通识词与透明复合词**：下游 LLM 能够独立稳定翻译的标准学校社团（如 `新聞部`、`生徒会`）、通识文化词（如 `七不思議`）、自解释复合词（如 `不思議調査隊`）以及现代日常外来语（如 `クラス`、`ピアノ`、`ナイフ`、`スマホ`），无需专名控制；
  4. **通用职业与泛用修饰**：普通职业、形容词短语或日常对话。
- **尚不能判断**：语境不足时，优先缩小边界或按输入上下文处理，确无策略时方列为需要补充信息。

---

## 2. 核心架构规约

### 2.1 全称与简称联动机制
- **全称条目**：承载完整身份、性别、能力与背景设定（如 `ノエル・フィン・デンペロン`）。
- **常用简称**：承载明确消歧指向与基本定位（如 `ノエル` -> “男性，主角诺艾尔·芬·登佩隆的常用简称”），防止长篇机翻时简称漏翻或指代漂移。

### 2.2 100% 真实字面命中红线
- 严禁凭主观推测加入原文未出现过的幽灵词条（例如原著仅出现“伯爵领”，严禁脑补“伯爵家”）。
- 导出前必须强制核验字面量出现频次，0 命中项一律剔除。

### 2.3 最小充分集合 (Minimal Sufficient Set)
- 优先保留语义独立完整的专有实体；
- 复合词与修饰扩展词若可通过核心词稳定覆盖且无歧义，严禁保留长词扩展变体，杜绝无节制膨胀。

### 2.4 `info` 字段高价值精简规范（零剧透红线）
- `info` 唯一目标是为下游翻译提供直接、高价值的提示（Actionable Prompt Hint）：
  - **角色**：必须标注性别（决定第三人称代词他/她），辅以核心身份/辈分（决定口吻称谓）；
  - **技能/道具**：标注动作类型与属性（如“近战物理剑技”、“范围魔法”，指导动词搭配）；
  - **地名/设施**：标注类别属性（如“学校名”、“异界区域”，防止误判为人名）；
- **严禁剧透**：严禁出现生平履历、遇害解谜、凶手动机、门禁刷卡等与用词修饰无关的小说剧情梗概。
- **字数控制**：单条 `info` 严格控制在 10~20 字以内。

### 2.5 产物路径存放约束（硬红线）
- 所有提取候选、消歧条目及导出的 JSON / XLSX 术语表，**必须统一存放于工程根目录的 `glossary/` 文件夹**（如 `glossary/glossary_rules.json`、`glossary/glossary_rules.xlsx`），严禁散落于根目录或临时路径。

## 4. 自动化工具链支持

推荐复用 `@skill(quality-rule-create)` 内置工具链进行验证与导出：
```powershell
python .agents/plugins/lingua-Antigravity/skills/quality-rule-create/scripts/epub_glossary_toolkit.py export glossary/glossary_entries.json --json-out glossary/glossary_rules.json --xlsx-out glossary/glossary_rules.xlsx --verify-text glossary/extracted_text.txt
```
Python 脚本已内置 Windows UTF-8 管道安全自愈与 `glossary/` 默认路径归集，直接调用即可。
