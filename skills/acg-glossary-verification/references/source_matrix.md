# 权威数据源优先级矩阵与精准检索策略

本文档为 `@skill(acg-glossary-verification)` 的核心参考资料，定义外部核验时的数据源权威层级、题材动态适配准则与网络检索语法。

---

## 1. 权威数据源优先级矩阵 (Source Priority Matrix)

进行网络检索与译名仲裁时，遵循以下权威层级递进链：

| 权威层级 | 推荐数据源 | 适用场景与优势 | 仲裁权重 |
| :---: | :--- | :--- | :---: |
| **Tier 1（首选）** | **萌娘百科**（`moegirl.uk` / `zh.moegirl.org.cn` / `moegirl.icu`） | 中文二次元现行事实标准，覆盖角色、团体、声优、歌曲、舞台、技能、组织、网络梗等最全收录 | **最高** |
| **Tier 1（并列）** | **官方中文版 / 官方发行文本 / 官方企划设定**（游戏官中、动画版权方、出版社文库、偶像企划官网） | 原作者或版权方钦定的官方中文译名 | **最高** |
| **Tier 2（辅助）** | **Bangumi（bgm.tv）/ 中文维基百科** | 规范的人物名、STAFF、分集标题、正式译名列表 | **高** |
| **Tier 2（辅助）** | **百度百科 / 贴吧精华 / 相关领域核心社区** | 国内核心玩家/读者社区长期约定俗成的经典译名 | **中高** |
| **Tier 3（溯源）** | **日文维基百科 / Pixiv 百科事典 / 官方日文 Wiki / 文库官网** | 原文拼写溯源、假名来源考证、语源解析与消歧 | **中（用于核实原文）** |

## 2. 题材动态适配原则 (Genre Adaptation)

不同二次元题材具有不同的核心权威中心，仲裁前先判断作品题材，再动态调整 Tier 1 权重：

1. **校园偶像与多媒体企划**（如《Love Live!》《BanG Dream!》《偶像大师》《少女☆歌剧》）：
   - **最高权重**：企划官方中文官网、版权方代理译名、官方声优活动/Live 定名。
   - **次高权重**：萌娘百科对应企划专题页面。
2. **日式奇幻与异世界轻小说**（如《Re:从零》《无职转生》《为美好的世界献上祝福！》）：
   - **最高权重**：角川/文库中文正版译本、官方授权手游官中。
   - **次高权重**：萌娘百科轻小说条目、主流轻小说翻译贴吧/核心专区。
3. **机战与科幻**（如《机战》《Muv-Luv》《高达》）：
   - **最高权重**：官方万代/机战官方中文、机甲设定集文库。
   - **次高权重**：萌娘百科、经典机战玩家社区论坛（如 MSL、机战世界）。
4. **多 IP 跨界与同人二次创作**：
   - 必须隔离各原作 IP，分别归入对应原作的官方定译，杜绝跨 IP 混同。

## 3. 高效精准检索策略 (Knowledge-First & On-Demand)

为防止上下文污染与无效工具调用，严禁盲目发起全量逐条检索。

### 3.1 检索触发判定
- **大模型内化直接判定**：主流高知名度经典角色、常见招式与高频词汇（如御坂美琴、誓约胜利之剑），直接采用标准定译，免联网。
- **按需触发联网（调用 `search_web`）**：
  1. 生僻外来语（片假名西文、德文、俄语借词）；
  2. 存在历史版本严重汉化分歧且当前内化权重不确定；
  3. 无法断定属于原作设定还是作者特有同人私设；
  4. 遇到系列续作/外传，需考证前作主角与世代关联。

### 3.2 推荐检索语法
- **精准百科定向**：`"萌娘百科" "作品名" "角色/技能/团体名"`
- **多词锚定比对**：`"作品名" "日文原名" "中文"`
- **官方/文库定译考证**：`"作品名" "原名" "官方" OR "文库"`
- **系列续作溯源**：`"前作作品名" OR "作者名" "角色名"`

## 4. 两级权威检索路由规程 (Two-Tier Routing Protocol v2.2)

对于日文轻小说/EPUB 实体，严禁直接使用模糊中文机翻标题泛搜，必须执行两级垂直检索：

### 第一级：权威原版锚定 (Original Metadata Anchor)
- **强制提取 OPF 元数据**：若输入为 EPUB，必须由工具链解析 `content.opf`，提取 `<dc:title>` 原版法定日文书名与 `<dc:creator>` 原作者名；
- **原文唯一标识**：以日文原名作为绝对基准，杜绝第三方翻译书名歧义。

### 第二级：定向垂直检索 (Vertical Domain Search)
- **禁止全网宽泛搜索**：防止搜索引擎返回贴吧脑补或无关内容；
- **平台定向语法**：
  - **角川 Kakuyomu 专栏**：`site:kakuyomu.jp "<原版日文标题>" "<作者名>"`
  - **小说家になろう 专栏**：`site:syosetu.com "<原版日文标题>"`
- **提取目标**：官方角色介绍（Character Profile）、主角假名注音（Furigana）以及特定魔法/招式的日文汉字与片假名对照。
