# 角色扮演开局交互范式与模板 (Opening Templates)

本文档为 `@skill(roleplay)` 的参考示例，展示开局第一轮向搭档公开回复的标准 Markdown 视觉组织范例。首次回复只进行世界呈现与偏好确认，不进入故事正文。

---

## 开局标准五步交互范例

### 1. 🌍 世界速览
简明扼要地向搭档说明：当前世界的基本风貌、科技/魔法水准、日常运转逻辑，以及身处其中的普通人正面临何种生存挑战或社会规则束缚。

### 2. 🎭 可扮演角色（候选选择表）
使用候选选择表列出主要候选角色及其处境：

| 选项 | 角色名与身份 | 当前处境与核心冲突 |
| :---: | :--- | :--- |
| **1** | **诺艾尔·芬·登佩隆**（年轻领主） | 刚刚继承动荡的边境领地，内有家臣派系掣肘，外有异族边患威胁 |
| **2** | **艾莉西亚**（流浪魔法学者） | 隐姓埋名逃脱帝国魔法学会追捕，携带着未解密的古代禁忌文书 |
| **3** | **自定义角色** | 由搭档自由指定姓名、身份与初始背景 |

### 3. 🎬 推荐开局
提供 3 个相容但体验迥异的切入点：
- **开局 A【静水深流】**：领主府深更半夜的紧急密报送达，面对暗流涌动的抉择；
- **开局 B【危机降临】**：边境巡逻途中突遇反常的魔兽异动与被袭马车；
- **开局 C【日常序曲】**：年度税赋清算会议前夕，各派系代表在走廊中言语试探。

### 4. ⚙️ 开局设置（字段填写表）
使用字段填写表确认游戏参数：

| 项目 | 当前值或默认值 | 需要填写或可如何修改 |
| :--- | :--- | :--- |
| **扮演角色** | 诺艾尔（选项 1） | 可选择上述角色或直接输入自定姓名 |
| **开局时点** | 开局 A | 可从上述选项中选择或自定场景 |
| **叙事视角** | 第三人称限知视角 | 可改为第一人称或全知视角 |
| **输出语言** | 中文（简体） | 可指定日文或其他目标语言 |
| **回合长度** | 约 2000~3000 字 | 依搭档阅读偏好调整篇幅 |
| **剧透与分支** | 自由分支探索 | 是否严格遵循原作主线，或允许产生蝴蝶效应 |

### 5. 🎮 玩法说明
末尾附带温馨提示：自由输入始终有效，随时可以通过对话修正剧情走向；选择将产生不可逆的因果痕迹。

👉 **请搭档在上述选项中指定你的角色与开局偏好，或直接自由回复你的设定！**
