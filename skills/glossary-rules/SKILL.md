# 术语领域判据

glossary 承载普通翻译无法稳定推出的专有译法、身份、消歧和世界观事实。规则维护不依赖质量规则启用状态；字段、匹配和变更行为以当前 workspace contract 为准。

运行时按 `src` 连续字面命中激活条目，把 `src -> dst #info` 交给翻译模型。`info` 是模型能够理解的语义或条件指令，不是程序执行的谓词；程序侧术语应用检查仍按命中 `src` 后是否出现固定 `dst` 判断，不解析 `info`。

## 1. LinguaGacha 标准术语表格式（5 字段契约）

所有提取、生成与导出的术语必须严格符合 LinguaGacha 标准结构（范本参考 `露西.json` 与 `露西.xlsx`）：

| 字段 | 类型 | 必填 | 说明与要求 |
| :--- | :---: | :---: | :--- |
| `src` | string | 是 | 原文（精确连续字面量，不使用正则） |
| `dst` | string | 是 | 译文（非空固定目标翻译） |
| `info` | string | 是 | 注释说明（包含角色性别/身份背景/实体类型/必杀技/设定/消歧条件；无特殊说明时为 `""`） |
| `regex` | boolean | 是 | 是否使用正则表达式；**实体术语表中固定为 `false`**（按字面量精确匹配） |
| `case_sensitive` | boolean | 是 | 是否大小写敏感；**默认为 `false`**（不区分大小写），仅当存在真实大小写冲突时设为 `true` |

### JSON 格式范例（数组形式）
```json
[
    {
        "src": "ルーシィ",
        "dst": "露西",
        "info": "主角的伙伴宠物（粉色粘液生物，魔法少女的吉祥物），可变身为女性魔法少女",
        "regex": false,
        "case_sensitive": false
    },
    {
        "src": "天神川恵梨香",
        "dst": "天神川惠梨香",
        "info": "女性，伊丽莎白（枪骑兵·伊丽莎白）的本名",
        "regex": false,
        "case_sensitive": false
    },
    {
        "src": "イア",
        "dst": "咿呀",
        "info": "邪神系存在的呼喊/口癖；仅在该词独立作感叹呼喊时采用本条（如「イア！イア！ルーシィ！」），其他词按普通词翻译",
        "regex": false,
        "case_sensitive": false
    }
]
```

## 2. 收录与表达能力

先独立判断对象是否需要 glossary，再判断怎样表达：

- **应收录**：对象已经能够确定为专有实体、作品特有概念或其它需要固定译法、身份、指代或消歧的内容；没有 glossary 时，合理译者可能产生足以破坏一致性的分歧。
- **不应收录**：属于普通称谓、职业、描述性或泛用内容，普通翻译能稳定得到目标结果。
- **尚不能判断**：补充调查后仍无法判断；继续尝试按输入语境处理、缩小边界或拆分，只有当前字段确实无法表达任何可执行策略时才列为需要补充信息。

人名、别名、姓氏、地名、家族、组织，以及作品特有的物品、技能、生物或概念，在身份可以合理建立时默认应收录。

## 3. 字段与证据

- `src`：`item.src` 或 `item.name_src` 中的精确连续字面量，不使用正则。
- `dst`：非空固定译文。
- `info` 撰写规范：
  - 角色条目：必须明确指出性别（如“女性，……”、“男性，……”），若有身份/职业/别名/关系应一并补充（如“主角的伙伴宠物，可变身为女性魔法少女”、“男性，天神川家执事”）。
  - 专有名词/地点/组织：标明实体类型（如“魔法少女战队”、“公司名”、“主角就读的小学”）。
  - 技能/必杀技/设定：标明属性与所属（如“暗黑露西的必杀技”、“世界观概念”）。
  - 条件消歧：明确指出生效语境与非生效时的处理原则（例如：“邪神系存在的呼喊/口癖；仅在该词独立作感叹呼喊时采用本条，其他词按普通词翻译”）。
- `regex`：指示是否使用正则表达式。在实体术语表中固定为 `false`（表示按精确字面量连续匹配，不进行正则转义与模式展开）。
- `case_sensitive`：指示是否大小写敏感。默认为 `false`（不区分大小写，以扩大覆盖面）；当且仅当原文中大小写不同代表完全不同的实体或普通词（如专有名词 `May` 与普通助动词 `may`）时，设为 `true` 以隔离碰撞。

## 4. 最小充分集合

按收录资格、正确性、充分性、作品风格、一致性、最小性的顺序从应收录对象构造最终集合：

1. 按照共享工作流结构组确认语义身份。
2. 确认子集内多词形确实相关后，调用 `workspace.deriveCommonLiteralRoots({ forms })` 枚举公共连续片段。
3. 把候选词根与拟替代分支交给 `workspace.matchLiterals` 验证覆盖（比较分支并集 B 与词根并集 R）。
4. 满足 R = B（或新增匹配 R > B 均耗尽且可正确处理）时采用词根，否则回退精确规则。
