# 虚构写作规则

统一解释什么使虚构叙事成立，以及如何在多种合理写法中保护人物、世界、因果与阅读体验。本技能只提供创作知识，不独立确定任务步骤、交互格式、工程操作或持久化方式。

## 质量优先级

发生取舍时依次保护：

1. 用户明确建立的核心体验、事实、边界和表达意图。
2. 已经成立的事件因果、人物知识、世界规则与时空连续性。
3. 人物的欲望、责任、价值、关系、自主性和变化轨迹。
4. 当前章节、场景或段落真实承担的叙事功能。
5. 视角、叙事距离、信息公开与语言声音的一致性。
6. 清楚、准确、有选择的细节以及与内容相称的节奏。
7. 金句、反转、奇观、修辞密度和表面新鲜感。

## 情节与场景动力

- **欲望或责任 → 行动 → 现实反馈 → 重新解释 → 选择 → 代价与余波**
- 让反馈改变人物能够知道、拥有、相信、承诺或尝试的内容。
- 让场景成为一个连续的压力环境：进入时已存在矛盾，离开时至少一项条件真正改变。

## 人物作为行为系统

人物不是姓名、外貌、职业和性格标签的集合。根据以下因素推导行为：
- **刺激 → 可感知信息 → 注意筛选 → 主观解释 → 冲动与顾虑 → 选择 → 公开表达 → 余波**
- 把行为锚点写成带条件的选择规律：受到何种刺激先注意什么、怎样解释、采用什么策略、顾忌什么代价、在哪些边界前退缩。
- 区分人物真实需要、当前想要、自认为想要和愿意承认的内容。

## 对话与呈现系统

- 先判断人物此刻想通过说话获得什么：信息、同盟、体面、控制、安慰、距离或退路。
- 会改变信息、立场或关系的关键对话直接写出具体措辞、轮次和停顿。
- 维护与当前行动有关的位置、朝向、距离、可触及范围和障碍。

## 创作诊断速查

| 症状 | 首要检查 | 重构方向 |
| --- | --- | --- |
| 人物只剩外貌与标签 | 行为证据、欲望与代价是否进入选择 | 重建带条件的行为锚点 |
| 对话像轮流介绍设定 | 说话者是否有不同目的、知识与风险 | 删除共同知识，恢复博弈与权力关系 |
| 多人场景动作混乱 | 人物、动作、物件、感知是否明确归属 | 逐项恢复行动者、对象与观察位置 |
| 场景气氛浓但无推进 | 进入压力、变量、选择与退出状态 | 让环境或互动改变信息、关系或行动空间 |
