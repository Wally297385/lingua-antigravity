# 避坑指南与质量核查清单 (Bad Case Checklist)

本文档为 `@skill(acg-glossary-verification)` 的核心参考资料，汇集泛二次元术语核验与仲裁过程中的常见陷阱、典型错误对照与交付前核验清单。

---

## 1. 典型错误与避坑准则

### 1.1 淘汰早期民间劣质音译
早期民间汉化或动画字幕组由于缺乏官方资料，常出现音译偏差。当权威源（萌娘百科/官中）已有标准条目时，必须强制淘汰旧译：

| 错误/陈旧民间译法 | 权威标准校准译名 | 原文与考证说明 |
| :--- | :--- | :--- |
| 神宫司球茉 | **神宫司麻理茉** | `神宮司まりも`（《Muv-Luv》，“まりも”为植物绿球藻，官方汉化定为麻理茉） |
| 伊隅满 | **伊隅美知留** | `伊隅みちる`（《Muv-Luv》，女主角名字为平假名女性名，非“满”） |
| 艾克塞琳 | **艾克瑟莲** | `エクセレン・ブロウニング`（《超级机器人大战OG》，Excellen 标准定译） |
| 库鲁茨 | **克鲁兹** | `クルツ・ウェーバー`（《全金属狂潮》，Kurz 德语定译） |

### 1.2 严禁将专名属性的日语汉字生硬直译
部分日文专有名词带有特殊读音或名讳习惯，不能机械按中文单字映射：
- ❌ 误：将 `伊隅みちる` 意译为单字「伊隅满」
- ✅ 正：统一遵循主流定译「伊隅美知留」
- ❌ 误：将 `オルタネイティヴ計画` 生硬意译为「替代方案计划」
- ✅ 正：保留世界观专有代号「Alternative计划」

### 1.3 严格隔离实体与从属技能/装备/台词
严禁将实体（机体/人物/角色）与从属于它的技能、武器或台词混淆为同一个词条：
- ❌ 混淆：把机体 `ダイゼンガー`（大前卡）与武器 `斬艦刀`（斩舰刀）合并为一个条目
- ✅ 隔离：
  - `ダイゼンガー` -> `大前卡`（实体机体）
  - `斬艦刀` -> `斩舰刀`（独立装备/技能）

### 1.4 偶像企划与多媒体企划特殊规约
- 团体名、企划名（如 μ's、Aqours、Poppin'Party、Roselia 等）严禁任意翻译，除非官方存在法定中文名称。
- 角色姓名与分队名（Unit）必须严格与官方中文代理或企划公布译名一致。

## 2. 交付前质量核查清单 (Pre-flight Checklist)

在导出或提交前，逐项进行硬性核验：

- [ ] **用户锚定词一致性**：搭档显式指定的角色名（如指令或书名中出现）是否已作为最高基准并统一所有复合词？
- [ ] **幽灵词条 100% 拦截**：所有拟导出条目的 `src` 是否已在正文文本中命中（命中次数 $\ge 1$）？未命中的脑补条目是否已彻底剔除？
- [ ] **原创/同人私设标注**：全网无收录且确认为作者自创的实体，是否在 `info` 中明确标注 `【本书特有】` 或 `【同人原创设定】`？
- [ ] **原文笔误消歧**：是否对作者原著笔误（如错字假名）建立了映射，并在 `info` 中标注 `【原文笔误消歧】`？
- [ ] **Excel rules 工作表规范**：生成的 XLSX 工作表名是否严格为 `"rules"`？`regex` 与 `case_sensitive` 是否为全大写的布尔值 `FALSE`？
